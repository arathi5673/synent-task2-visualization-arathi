# Task 2 - Iris Dataset Visualization

## Problem Statement
Visualize patterns in the Iris dataset using 
different types of charts and graphs.

## Dataset
- Name: Iris Dataset
- Source: sklearn library (built-in)
- Shape: 150 rows, 5 columns
- Features: sepal length, sepal width, 
  petal length, petal width, species

## Approach
- Loaded Iris dataset using sklearn
- Created Bar chart to show species count
- Created Histogram to show sepal length distribution
- Created Scatter plot to compare sepal and petal length
- Created Pair plot to compare all features

## Results
- Setosa species has smaller petal size
- Virginica has the largest petal length
- Clear separation between species visible in scatter plot
- All 3 species have equal count of 50 each

- Bar Chart ✅
- Histogram ✅
- Scatter Plot ✅
- Pair Plot ✅
